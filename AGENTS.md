# AGENTS.md

## Context

A fintech company runs a handful of internal tools on a low-code platform
and plans to build ten more. The question is whether owning the platform
beats renting it.

This repo is the answer: build once the layer that a low-code platform
gives you for free — identity, roles, audit trail, base UI — and make
generating a new app on top of it trivial. Every app is real code the
team can edit afterwards, not a configuration living inside someone
else's runtime.

That last part is the whole point. If a generated app can't be edited
like normal code, this project has failed.

## What this is

Two layers:
- `foundation/` — auth, roles, audit, base UI. Written once, owned, stable.
- `apps/` — generated by the scaffold. Real code, editable, disposable.

## Hard rules

- Nothing in `foundation/` or `scaffold/` may reference a business domain.
  No "kyc", "ticket", "refund" anywhere in those directories.
- Every database write goes through `foundation/audit.py`. There is no
  second write path. Adding one is a bug.
- Generated apps use real tables and real foreign keys. No JSON blobs
  standing in for a schema.

## Stack

Python 3.11, FastAPI, SQLAlchemy, SQLite (dev), Jinja2 templates + HTMX.
No React build step.

## Conventions

- Migrations with Alembic, one per app.
- Tests in `/tests`, pytest.
- Commit messages: imperative, one line.
